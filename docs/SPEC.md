# 需求规格（MVP）

只描述第一版要做的内容。未列出的功能一律不做。

## 不做（本期）

登录与账号、宝宝档案、收藏与打卡、评论与社区、支付与课程、AI 问答、原生 App、后端接口。

## 路由

| 路由 | 页面 |
|---|---|
| `/` | 首页 |
| `/activities` | 活动库 |
| `/activities/[slug]` | 活动详情 |
| `/activities/[slug]/play` | 分步全屏模式 |
| `/guides` | 家长课堂列表 |
| `/guides/[slug]` | 文章详情 |
| `/milestones` | 成长地图 |
| `/library` | 绘本与歌谣 |
| `/calendar` | 月龄日历（13 个月） |
| `/search` | 搜索 |
| `/about` | 关于、审核机制、免责声明、隐私 |

## 全局

- 手机端：顶部 Logo + 搜索入口；底部固定导航（首页、活动、日历、关于）。
- 桌面端（≥820px）：顶部横向导航；内容最大宽度 980px。
- 页脚固定显示：发育个体差异与“不能替代医生诊断”的声明。
- 月龄为全局状态（24–36，默认 28），保存在 `localStorage`。

## 首页

**模块**：月龄选择、能力筛选标签、“抽一个游戏”按钮、结果便签、本月主题、家长常问、页脚。视觉与交互以 `prototype/home.html` 为准。

**抽取规则**
1. 候选集 = 满足 `minMonth ≤ 当前月龄 ≤ maxMonth` 且（能力为“全部”或等于所选能力）的已发布活动。
2. 候选集中排除上一次抽到的活动（候选只有 1 个时除外），再随机选一个。
3. 候选集为空时，显示提示“这个月龄暂时没有对应的游戏，换一个能力，或把月龄调大一点再试。”
4. 结果便签显示：标题、能力、时长、起始月龄、材料、玩法、在练什么、安全提醒（若有），以及“查看完整页面”链接。

**验收**
- 未抽取前显示空状态引导文案。
- 抽取与筛选逻辑为纯函数，有单元测试：空候选、单候选、不连续重复、月龄边界。
- 筛选标签有 `aria-pressed`，结果区有 `aria-live="polite"`。
- 无 JS 时页面仍可阅读，并提供“浏览全部活动”的链接。

## 活动库 `/activities`

- 列表卡片：标题、能力标签、时长、起始月龄、材料数量。每页 20 条，“加载更多”。
- 筛选：能力（多选）、月龄（单值，默认取全局月龄）、时长（5 分钟内 / 10 分钟 / 15 分钟以上）、场景（室内 / 户外 / 雨天 / 睡前）、材料（无需材料 / 家中常见物品 / 需购买）。
- 排序：最新、时长从短到长。
- **验收**：筛选条件同步到 URL 查询参数，刷新或分享后结果一致；无结果时显示“清除筛选”按钮；筛选结果即时更新。

## 活动详情 `/activities/[slug]`

**固定结构（按顺序）**：标题与一句话亮点 → 元信息（能力、起始月龄、时长、场景）→ 所需材料（可勾选清单）→ 玩法步骤（3–5 步，每步可配图）→ 在练什么 → 宝宝不配合怎么办 → 进阶玩法 → 安全提醒（高亮框，若有）→ 相关活动（3 个，优先同能力）→ “开始玩”按钮。

**验收**：所有字段来自内容 schema；缺少可选字段时对应区块不渲染；每张图有 `alt`；输出 `HowTo` 结构化数据。

## 分步全屏模式 `/activities/[slug]/play`

- 每页显示一步，顶部显示进度（如 2 / 3）和关闭按钮；底部“上一步 / 下一步”大按钮，高度 ≥ 56px。
- 最后一步的按钮文案为“完成”，返回详情页。
- 请求屏幕常亮（Wake Lock API，不支持时静默忽略）。
- 支持键盘左右方向键。

## 家长课堂 `/guides`

- 列表按分类展示：情绪与行为、语言、生活自理、入园准备、屏幕时间、安全。
- 详情：摘要、正文、审核人、参考来源、更新时间、相关活动。
- `reviewer` 为 `PENDING` 时在文章顶部显示“待专家审核”提示。

## 成长地图 `/milestones`

- 按 6 个领域展示 24–36 个月的里程碑，分“多数宝宝能做到”和“可以多留意”两栏。
- 页面顶部固定声明：发育有个体差异，仅供参考，不能替代专业诊断。
- 每个领域页底部有“什么时候建议咨询医生”区块（内容待专家提供）和相关活动。

## 绘本与歌谣、月龄日历、搜索

- 绘本：简介、适合月龄、亲子共读小提示。封面图在拿到授权前使用占位图。不收录受版权保护的歌词全文。
- 月龄日历：13 个月，每月一个主题、一个重点能力、4 个推荐活动、2 篇文章。
- 搜索：Pagefind（对静态导出的 `out/` 建索引），覆盖活动、文章、绘本；支持中文；提供 3–5 个热门搜索词。

## 非功能要求

| 项目 | 要求 |
|---|---|
| 性能 | 移动端 4G：LCP ≤ 2.5s，CLS ≤ 0.1，首屏 JS ≤ 150KB |
| 兼容 | iOS Safari 15+，Android Chrome 100+，微信内置浏览器，桌面浏览器近两个版本 |
| SEO | 每页独立 title 与 description，生成 sitemap，文章输出 Article 结构化数据 |
| 无障碍 | 见 AGENTS.md |
| 部署 | 纯静态导出（`out/`），部署到 Cloudflare；不使用任何服务端运行时功能 |
| 404 | 不存在的路径返回 404 页面，并提供回到首页和活动库的入口 |
