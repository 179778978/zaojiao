# 开发任务清单

按顺序完成，一次一个。完成后勾选，并在任务下写一两句说明。

## T0 初始化项目
- [x] 用 Next.js App Router + TypeScript strict 初始化项目配置。
- [x] 采用本包中的静态导出、Wrangler、设计令牌与内容校验配置。
- [x] 配置应用与开发依赖、ESLint、Vitest 和 npm scripts。
- **验收**：`npm run build` 通过并生成 `out/`；`npm run preview` 能打开页面。
  说明：初始骨架与配置已完成；构建验收待依赖安装后运行。

## T1 设计令牌与基础布局
- [x] 在根 layout 引入设计令牌；实现 Header、Footer、手机底部导航、深色模式。
- [x] 配置 ZCOOL KuaiLe 与 Noto Sans SC 字体及回退栈。
  说明：完成全站布局与移动导航，颜色和圆角使用设计令牌。
- **验收**：浅色/深色模式都正常；手机底部导航固定；页脚在所有页面可见；无硬编码颜色。

## T2 内容校验
- [x] 完成活动、文章及里程碑 JSON 的 schema 内容校验。

  说明：校验脚本会指出无效文件；命令结果待依赖安装后确认。
- **验收**：删掉某个必填字段后 `npm run content:check` 和 `npm run build` 都失败，并指出文件名。

## T3 通用组件
- [x] 实现活动卡片、能力标签、可访问筛选芯片、便签和折叠问答。

- **验收**：只使用令牌变量；三种不规则圆角交替使用；键盘可操作，焦点可见；有基本的组件测试。

## T4 首页

- [x] 月龄用默认值首屏渲染，挂载后从 `localStorage` 读取。
  说明：详情与筛选状态按活动数据生成；待依赖安装后跑测试验证。
- **验收**：SPEC“首页”验收全部满足；与原型视觉一致；无 JS 时有“浏览全部活动”链接；无水合警告。
